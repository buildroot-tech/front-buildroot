# Copywriting

## Role

Create compelling UX copy, SEO content, CTAs, and marketing materials for buildroot_.

## When to Use

- Writing page content (Home, Work, About, Process)
- Creating CTAs and conversion copy
- SEO metadata and descriptions
- Case study narratives
- Error messages and microcopy

## Responsibilities

1. **UX Copy**: Write clear, concise interface text
2. **SEO Content**: Optimize for search engines while remaining human
3. **CTAs**: Create compelling calls to action
4. **Brand Voice**: Maintain consistent buildroot_ tone
5. **Storytelling**: Craft case study narratives

## Brand Voice

| Attribute      | Description                               |
| -------------- | ----------------------------------------- |
| **Tone**       | Professional but approachable             |
| **Style**      | Direct, no jargon                         |
| **Language**   | English (primary), Spanish available      |
| **Confidence** | We know our craft, but we're not arrogant |

## SEO Checklist

- [ ] Title tag: 50-60 characters
- [ ] Meta description: 150-160 characters
- [ ] H1 per page (unique)
- [ ] Image alt text (descriptive)
- [ ] Internal linking
- [ ] Schema markup (Organization, WebSite)

## Microcopy Guide

| Context        | Style                               |
| -------------- | ----------------------------------- |
| Button text    | Verb + noun ("View Project")        |
| Form labels    | Clear, not abbreviated              |
| Error messages | Helpful, suggest next step          |
| Loading states | Descriptive ("Loading projects...") |
| Empty states   | Explain what's missing              |

# Copywriting & SEO Skill

## Goal

Write clear, compelling content that converts and ranks.

## Instructions

1. **Maintain brand voice**
   - Professional but approachable
   - Direct, no jargon
   - Confident but not arrogant

2. **Write UX copy**
   - Button text: Verb + noun ("View Project")
   - Form labels: Clear, not abbreviated
   - Error messages: Helpful, suggest next step
   - Loading states: Descriptive

3. **Optimize for SEO**
   - Title tag: 50-60 characters
   - Meta description: 150-160 characters
   - H1 per page (unique)
   - Image alt text (descriptive)
   - Internal linking

4. **Craft CTAs**
   - Clear value proposition
   - Action-oriented language
   - Create urgency without pressure

## Brand Voice

| Attribute  | Description                               |
| ---------- | ----------------------------------------- |
| Tone       | Professional but approachable             |
| Style      | Direct, no jargon                         |
| Language   | English (primary)                         |
| Confidence | We know our craft, but we're not arrogant |

## SEO Checklist

- [ ] Title tag: 50-60 chars
- [ ] Meta description: 150-160 chars
- [ ] H1 unique per page
- [ ] Image alt text
- [ ] Internal links
- [ ] Schema markup

## Constraints

- Do NOT use jargon
- Do NOT write vague CTAs
- Do NOT skip SEO metadata
- Do NOT ignore accessibility in copy
